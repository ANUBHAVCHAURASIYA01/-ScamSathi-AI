# ScamSathi AI — Streamlit prototype

A simple web app that checks a pasted message for common scam warning keywords.

## Deploy for free with Streamlit Community Cloud
1. Upload `app.py`, `requirements.txt`, and `README.md` to a GitHub repository.
2. Open https://share.streamlit.io/
3. Choose **Create app** / **New app**.
4. Select your repository, branch (usually `main`), and main file path `app.py`.
5. Click **Deploy** and wait for the app to start.

## Limitations
This is a keyword-based prototype, not a trained AI model. It can miss scams and flag legitimate messages. A low-risk or no-keyword result does not mean a message is safe. Never enter real OTPs, passwords, UPI PINs, CVVs, or other sensitive information.
For cyber financial fraud in India, call 1930 promptly or report at https://cybercrime.gov.in/.
